AI systems architect based in Germany. I run Taktitekt, an external digital department for businesses.

I design and build AI and automation systems for businesses, with one
rule: the AI does the repetitive work, and a person keeps the judgment.

## Open-source projects

- [Project memory for AI agents](https://github.com/marcoaestrada/project-memory-for-ai-agents) — Markdown templates for shared project rules, current state, decisions and open tasks. Available in English and Spanish.
- [Prelaunch Check](https://github.com/marcoaestrada/prelaunch-check) — A Python command-line tool for checking indexing, protected pages, redirects and page basics before a website launch.
- [Human Approval Gate](https://github.com/marcoaestrada/human-approval-gate) — A Python library and command-line tool for recording proposals and approvals before running actions, with a hash-chained event log.
